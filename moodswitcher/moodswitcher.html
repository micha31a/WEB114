Project 7 -- DOM and JS

JavaScript Questions

  1. Why is textContent safer than innerHTML?

    Answer: textContent only affects strictly the plain text of the element, whereas innerHTML affects all of the HTML within that element. This means any changes you make with JS will only affect the text as intended, and it prevents more of your code being accessed.

  2. How are HTML elements connected to JavaScript variables using DOM selection?

    Answer: The DOM allows JavaScript to access and store HTML elements within variables, so that our JavaScript code can reference and use HTML elements to change styles, content, etc.

  3. What would happen to the text box with id="text" if I added this line to the code above it: text.textContent = "Hello!"

    Answer: The text would be replaced with the phrase "Hello!".
